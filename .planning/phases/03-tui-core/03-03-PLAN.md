# StateStore API Available

- getPin(name): !HalValue (reads current cached value)
- getSignal(name): !HalValue
- getParam(name): !HalValue
- listPins/listSignals/listParams for enumeration

# RefreshThread API Available

- init(allocator, store): Initialize refresh thread
- start(): Spawn background thread
- stop(): Signal shutdown and wait
- setInterval(ms): Adjust refresh rate (default 100ms)

# SubscriptionManager API Available

- subscribe(item_name, callback): Register change notification
- notify(item_name, old_val, new_val): Broadcast change
- Callback signature: fn (name: []const u8, old: ?HalValue, new: HalValue) void

# Research Context

RESEARCH.md Pattern 3: Pubsub-Driven Redraws
- Subscribe to value changes in .init event handler
- Callback triggers redraw via ctx.consumeAndRedraw()
- Only redraw when state changes (prevents lag)

RESEARCH.md Pitfall 2: Blocking Event Loop
- Never call HAL functions from TUI event handlers
- Only read from StateStore cache (fast, lock-free reads)

RESEARCH.md Pitfall 6: Editable vs Read-Only Visual Distinction
- Use vaxis.Style with color indices
- Green (index 2) for editable, dim gray (index 8) for read-only
- Determine editability: writable params and OUT/I/O pins are editable
