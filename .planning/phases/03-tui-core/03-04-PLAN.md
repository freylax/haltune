# FFI Write Operations Available

Plan 03-00 added these functions to src/ffi/safe.zig:
- Pin write: pinBitSet(?[*c]volatile u8, bool) !void
- Pin write: pinFloatSet(?[*c]volatile f64, f64) !void
- Pin write: pinS32Set(?[*c]volatile i32, i32) !void
- Pin write: pinU32Set(?[*c]volatile u32, u32) !void
- Param write: setParamBit(?*hal_param_t, bool) !void
- Param write: setParamFloat(?*hal_param_t, f64) !void
- Param write: setParamS32(?*hal_param_t, i32) !void
- Param write: setParamU32(?*hal_param_t, u32) !void
- Pin read: getPinValue(?*const hal_pin_t) !HalValue

All write functions:
- Acquire HAL mutex before modifying values
- Return error.NotFound if pointer is null
- Return error.TypeMismatch if type doesn't match (params only)
