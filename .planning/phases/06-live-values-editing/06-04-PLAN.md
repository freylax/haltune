/// Delete a HAL signal
///
/// Removes a signal from the HAL. All pins linked to this signal
/// will be unlinked first. The signal must exist.
///
/// Parameters:
///   - name: Null-terminated signal name to delete
///
/// Returns:
///   - void on success
///   - error.NotFound if signal doesn't exist
///
/// Thread safety:
///   - hal_signal_delete acquires HAL mutex internally
pub fn halSignalDelete(name: [:0]const u8) !void {
    if (c.hal_signal_delete(name) < 0) {
        return HalError.NotFound;
    }
}

1. Add countPinsForSignal to count connected pins (after updatePinLink):

```zig
/// Count how many pins are linked to a signal
///
/// Iterates through pin_links to count connections to the given signal.
/// Used to determine if a signal is orphaned (no pins connected).
///
/// Parameters:
///   - signal_name: Signal name to count pins for
///
/// Returns:
///   - Number of pins linked to this signal
pub fn countPinsForSignal(self: *const StateStore, signal_name: []const u8) usize {
    self.rwlock.lockShared();
    defer self.rwlock.unlock();

    var count: usize = 0;
    var iter = self.pin_links.iterator();
    while (iter.next()) |entry| {
        if (std.mem.eql(u8, entry.value_ptr.*, signal_name)) {
            count += 1;
        }
    }
    return count;
}
```

2. Add removeSignal to delete signal from store (after updateSignal):

```zig
/// Remove a signal from the store
///
/// Deletes a signal from the signals HashMap and frees its value memory.
/// Call after halSignalDelete to keep local state in sync.
///
/// Parameters:
///   - name: Signal name to remove
pub fn removeSignal(self: *StateStore, name: []const u8) !void {
    self.rwlock.lock();
    defer self.rwlock.unlock();

    if (self.signals.fetchRemove(name)) |entry| {
        // Free the HalValue union
        switch (entry.value) {
            .float => |f| if (f != 0.0) _ = f, // floats don't have alloc
            .s32, .u32, .bit => {},
        }
    }
}
```
