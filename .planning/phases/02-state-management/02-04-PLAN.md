  <name>Task 2: Implement refreshSignals function in RefreshThread</name>
  <files>src/state/refresh.zig</files>
  <action>
    Add refreshSignals() function following the exact same pattern as refreshPins() (lines 241-288):

    **Function signature:**
    ```zig
    fn refreshSignals(self: *RefreshThread) !void
    ```

    **Implementation steps (same 4-phase pattern as refreshPins):**

    1. **Discovery phase:** Enumerate all signals from HAL
       - Create `std.ArrayList(*c.hal_sig_t)` initialized with self.allocator
       - Call `ffi.halprFindSigByName(null)` to get first signal
       - Loop while signal is not null: append to ArrayList, move to next via `sig.*.next`
       - Defer ArrayList deinit

    2. **Snapshot phase:** Get current cache keys
       - Call `self.store.listSignals(self.allocator)` to get cached signal names
       - Defer free the returned slice

    3. **Comparison phase:** Find and add new signals
       - Loop through HAL signals ArrayList
       - For each signal, get name via `std.mem.span(sig.*.name)`
       - Check if signal exists in cached_names (nested loop comparison)
       - If not found (new signal), call `try self.store.addSignal(name, value)` with initial value

    4. **Update phase:** Read all current values and update cache
       - Loop through HAL signals ArrayList
       - Read signal value (call helper or inline logic)
       - Call `try self.store.updateSignal(name, value)`

    **Note:** Signal values are read similarly to pins but use hal_sig_t structure. Check safe.zig for getSignal* functions or add readSignalValue helper if needed.

    **Place function after refreshPins()**, around line 290.
  </action>
  <verify>
    grep -n "fn refreshSignals" src/state/refresh.zig
  </verify>
  <done>
    refreshSignals() enumerates HAL signals, discovers new ones, and updates all signal values at configured interval
  </done>
