  <files>src/state/pubsub.zig</files>
  <action>
    Add subscription management:

    1. subscribe(self: *SubscriptionManager, item_name: []const u8, callback: Callback) !void
    - Acquire mutex
    - Get or put SubscriberList for item_name in subscribers HashMap
    - If new entry: initialize ArrayList with allocator
    - Append callback to list
    - Release mutex

    2. unsubscribe(self: *SubscriptionManager, item_name: []const u8, callback: Callback) !void
    - Acquire mutex
    - Find item_name in subscribers HashMap
    - Remove callback from list (iterate and find matching pointer)
    - If list becomes empty: remove entry from HashMap
    - Release mutex

    Thread safety: mutex protects subscriber list from concurrent modification during subscribe/unsubscribe.

    Return error.NotFound if attempting to unsubscribe from non-existent item or callback not found.
  </action>
  <verify>zig build-lib -femit-bin=zig-cache/lib/pubsub.o src/state/pubsub.zig compiles without errors</verify>

<task type="auto">
  <name>Implement notify and waitForChange functions</name>
  <files>src/state/pubsub.zig</files>
  <action>
    Add notification system:

    1. notify(self: *SubscriptionManager, item_name: []const u8, old_value: ?HalValue, new_value: HalValue) void
    - Acquire mutex
    - Look up item_name in subscribers HashMap
    - If found: iterate subscriber list and call each callback
    - Set has_changes = true
    - Call condition.broadcast() to wake all waiting threads
    - Release mutex

    2. waitForChange(self: *SubscriptionManager) void
    - Acquire mutex
    - Loop while (!has_changes) { condition.wait(&mutex); }
    - Clear has_changes = false
    - Release mutex

    Follow RESEARCH.md Pitfall 2: Use while loop (not if) to handle spurious wakeups.

    The old_value parameter allows detecting:
    - First notification (old_value == null, new_value exists)
    - Actual changes (old_value != new_value)
    - No-op updates (old_value == new_value, subscribers still notified)
  </action>
  <verify>zig build-lib -femit-bin=zig-cache/lib/pubsub.o src/state/pubsub.zig compiles without errors</verify>
  <done>notify calls all subscribers and broadcasts condition; waitForChange blocks until changes occur (handles spurious wakeups)</done>
</task>
