    - Spawn thread using std.Thread.spawn with run() as entry point

    - Pass self as argument to run()

    2. run(self: *RefreshThread) void
    - Loop while self.running.load(.acquire) is true

    3. stop(self: *RefreshThread) void

    Read HAL values first, THEN acquire cache lock for update.

  <action>
    Add refresh logic:

    1. refreshHal(self: *RefreshThread) !void
    - List all pins from cache (snapshot names)
    - For each pin: read current value from HAL using ffi.getPin*
    - Update cache with new value using store.updatePin
    - Repeat for signals and params

    Implementation approach:
    - Call store.listPins(self.allocator) to get pin names
    - For each pin name: look up pin pointer from HAL (halpr_find_pin_by_name)
    - Read value using appropriate ffi.getPin* function
    - Update cache: try store.updatePin(name, value)
    - Free the name list after processing

    NOTE: HAL discovery API (halpr_find_pin_by_name, halpr_find_pin_by_name) may need to be added to c.zig or safe.zig if not already present.

    2. setInterval(self: *RefreshThread, interval_ms: u64) void
    - Update self.interval_ns = interval_ms * std.time.ns_per_ms
    - Allows runtime configuration of refresh rate

    Follow RESEARCH.md Pitfall 1: Read HAL values BEFORE acquiring cache lock.
  </action>
