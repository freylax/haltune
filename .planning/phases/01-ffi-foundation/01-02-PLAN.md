1. Import c from "c.zig" and errors from "errors.zig"
2. Implement halInit(comp_name: [:0]const u8) !c.hal_comp_t:
   - Call c.hal_init(comp_name)
   - Return InitFailed if null or negative
   - Return valid component ID on success
3. Implement halExit(comp_id: c.hal_comp_t) void:
   - Call c.hal_exit(comp_id)
   - No return value (always succeeds)
4. Implement halReady(comp_id: c.hal_comp_t) !void:
   - Call c.hal_ready(comp_id)
   - Return error if non-zero return code

Follow the pattern from RESEARCH.md Pattern 1 "Safe FFI Wrapper with Error Unions"

Note: Only wrap init/exit/ready in this task. Pin/signal wrappers come in the next plan.
