<task type="auto">
  <name>Implement pin wrapper functions in safe.zig</name>
  <files>src/ffi/safe.zig</files>
  <action>
Add pin-related wrapper functions to src/ffi/safe.zig:

1. pinNew(comp_id: c.hal_comp_t, name: [:0]const u8, type: c.hal_type_t, dir: c.hal_pin_dir_t) !*c.hal_pin_t:
   - Call c.hal_pin_new() with proper parameters
   - Return PinCreationFailed on error
   - Return valid pin pointer on success

2. setPinFloat(pin: *c.hal_pin_t, value: f64) !void:
   - Acquire HAL mutex: c.hl_mutex_lock(&c.hal_mutex)
   - Defer unlock: defer c.hl_mutex_unlock(&c.hal_mutex)
   - Check pin type matches HAL_FLOAT
   - Set value through pin.value.float pointer
   - Return TypeMismatch if wrong type

3. setPinBit, setPinS32, setPinU32 variants:
   - Same pattern as setPinFloat but for respective types

4. getPinFloat(pin: *const c.hal_pin_t) !f64:
   - Read current value from pin.value.float.*
   - Return TypeMismatch if wrong type
   - No mutex needed for read (HAL real-time thread owns writes)

Follow RESEARCH.md Pattern 4 "Mutex Locking for Thread Safety" and Pattern 3 "Memory Ownership with Explicit Lifetimes"

DO NOT free pin pointers - HAL owns them.
  </action>
  <verify>zig build compiles with all pin functions defined</verify>
  <done>safe.zig exports pinNew and 8 set/get functions (4 types x 2 directions)</done>
</task>
